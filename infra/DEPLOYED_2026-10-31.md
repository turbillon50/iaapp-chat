# IA.app CHAT — evidencia de infraestructura (31-oct-2026)

La entrega de cliente Flutter proviene de `krille-chan/fluffychat`, importado en PR #2 de este repositorio. Su código base usa AGPL-3.0-or-later.

## Servicio Matrix desplegado
- Host: Hetzner `v-forge`; contenedor `iaapp-chat-homeserver-1`.
- Motor: Continuwuity (RocksDB embebido), imagen pinneada `ghcr.io/continuwuity/continuwuity@sha256:c9c62bc5c0a641f3f713945c701b069c7bc30d2612b54d4a5de80a5be19d5420`.
- Server name reservado: `chat.iaapp.live`. **El DNS de esa dirección no está publicado todavía.**
- API pública accesible por ruta HTTPS independiente: `https://vchat.vforge.site/_matrix/client/versions`, respuesta HTTP 200 comprobada.
- Servicio local restringido a `127.0.0.1:4955`; datos persistidos en `/opt/iaapp-chat/continuwuity-data`. Registro público desactivado.
- Nginx añade exclusivamente `/_matrix/` a un origen HTTPS existente; la raíz existente de `vchat.vforge.site` siguió devolviendo 200 tras la recarga.
- Respaldo local de configuración Nginx anterior: `/opt/iaapp-chat/nginx-vchat-before.conf`.
- `/_matrix/client/v3/login` anuncia autenticación Matrix; verificación de preflight CORS desde GitHub Pages respondió 200.

## Lo que **no** está acreditado
- Identidad IAapp 100000 emparejada a una cuenta Matrix. Better Auth permanece aislado en su servicio actual y no hemos alterado usuarios reales.
- Inicio de sesión oficial ChatGPT o Gemini, vinculación de chats originales, entrega bidireccional entre Luis y Acevedo o federación externa.
- Cifrado E2EE extremo a extremo validado, backup restaurado, entrega de voz, notificaciones iOS nativas ni app instalada de tiendas.
- No se ha emitido un registro público ni compartido la credencial administrativa inicial en documentación.
- El disco del host está cerca del 97%; antes de crecimiento de usuarios se requiere política de capacidad, backups y observabilidad.

## Próximos gates para publicación comercial
1. Publicar cliente Flutter con fuente AGPL y pantalla IA.app aprobada.
2. Resolver DNS definitivo y federación con un entorno Matrix externo.
3. Alta de usuarios por invitación, vinculación con identidad Better Auth y dos teléfonos distintos.
4. QA E2EE y recuperación de claves; backups restaurables y alertas.
5. Integrar acceso ChatGPT/Gemini solo cuando el proveedor/puente de identidad lo permita realmente; distinguir de OAuth de un conector MCP.

El cliente podría utilizarse con cuentas Matrix propias o externas; el login de IAapp no está conectado aún. No marcar esta etapa como un lanzamiento completo.
